# Shop Management

Mobile-friendly shop management web app.

Features:
- Opening balance
- Withdrawal commission 1%
- Money transfer commission 1.5%
- Recharge commission 0%
- Aadhaar last 4 digits only for withdrawal and money transfer
- Daily report
- Closing balance
- Monthly profit
- Transaction history
- Browser localStorage

## GitHub Pages
Upload `index.html` to a public repository named `shop-management`.
Then go to Settings -> Pages -> Deploy from a branch -> main -> / (root) -> Save.

The app stores data in the browser's localStorage.
